# 飞象智能制卡 Demo

一个可运行的 Web 桌面原型，演示从试卷解析或模板建卡，到答题卡编辑、校验和发布的完整流程。当前版本为 v1.1.0。

## 推荐体验路径

1. 选择“新建空白卡”，打开模板中心，比较通用、北京英语、理科校本和真正空白卡。
2. 选择“真正空白卡”，在“基础信息”中设置名称、学科、时长与 1–4 页，再从任意页新增题块。
3. 新增客观题，设置题号、分值、A–D / A–E 与每栏题数；小高度会被内容容量检查拦截并可一键扩高。
4. 单击纸面标题直接修改；用撤销 / 重做验证标题与模板、题块共用完整文档快照。
5. 从编辑器顶部更换“理科实验与作图 · 校本模板”，可保留当前标题并整体替换题块结构。
6. 发布 V1 后再次修改标题，观察系统自动创建 V2 草稿，V1 印刷版保持不可变。

题库链路仍可按原流程体验：解析原创北京初三英语模拟卷，确认低置信结构后进入编辑器。

## 终端与预览

- Web 桌面端，推荐浏览器宽度不低于 1280px。
- 默认入口：`/`
- 过稿占位模式：`/?mode=review`

## 本地启动

```bash
npm install
npm run dev
```

## 构建与预览

```bash
npm run build
npm run preview
```

## 分享方式

1. 最快方式：执行 `npm run build`，将 `dist/` 打包发送。项目已设置相对资源路径；建议通过任意静态文件服务打开。
2. 发链接：将 `dist/` 拖入 Netlify，或使用 Vercel 部署。

## 目录说明

- `src/pages/`：页面编排。
- `src/components/`：制卡流程与编辑器组件。
- `src/features/answer-sheet/`：领域类型和状态转换。
- `src/data/`：原创模拟试卷与规则包数据。
- `src/services/`：可替换的 mock 服务边界。
- `src/design-system/`：飞象页面级 token、骨架与 zoom 适配。
- `AGENT-HANDOFF.md`：跨对话产品决策与边界。

## 当前 Mock

试卷上传与解析、自动保存、PDF生成、打印扫描、鉴权、权限、协作和埋点均为本地演示状态，不代表生产能力。
