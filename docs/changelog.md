## v1.2.0 · 2026-11-03

### 目标

- 已有试卷点击“答题卡”后直接进入编辑器，移除来源选择和解析中间页。
- 重构为左侧配置、右侧答题卡画布，完整承接 P0 字段与结构编辑。
- 模板只套用版式，不改变当前试卷的标题、学科、题号、分值和题块。
- 印前检查实时校验题号、题数、总分、内容容量、纸张与规则包，并支持完整多面打印。

### P0 实现

- 整卡：网阅/手批/混合，纯题卡/题卡合一，纸张、单双面、正反栏数、考号版式与位数、身份字段、条形码、注意事项、页脚与关联试卷。
- 结构：题号起点/跳号、页内拖动、跨页移动、集中客观题/主观题、拆分/合并、区域高度。
- 题块：模块标题、分值/题数独立显示、评分栏、实线/虚线、作文方格、括号/方块、自定义文字、表格/公式/图片结果与禁答区。

### 验收

- `npm run typecheck` 通过。
- `npm run build` 通过；仅 Metis 上游 CSS 压缩警告与 bundle 体积提示。
- 浏览器确认默认直达编辑器，页面不再出现“你想怎样开始”。

## v1.1.0 · 2026-11-03

### 目标

- 空白建卡先选择并预览模板，也可从真正空白卡开始。
- 试卷标题直接在答题卡画布内编辑，并与撤销、保存、版本发布保持一致。
- 模板套用替换完整编辑快照，避免出现“画布已换、校验仍是旧试卷”的状态错位。
- 真正空白卡可新增题块、填写题号范围和区域分值；总分自动汇总并参与印前校验。
- 空白卡可设置学段、学科、时长和 1–4 页基础信息，并在任意页继续制卡。
- 客观题支持 4 / 5 个选项和每栏建议题数；作文共用 / 独立作答区会真实改变版式。
- 题号范围采用安全解析；未配置题块、内容裁切、页面溢出和纸型不匹配会在发布前拦截。

### 参考吸收

- 智学网：空白卡、模板复用、题块化编辑。
- 新教育：画布即所得、标题与主观题区的直接操作。
- 飞象改进：模板缩略预览与适用信息、低参数入口、切换结果可撤销、发布前统一校验。
